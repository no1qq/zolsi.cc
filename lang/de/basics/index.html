Vier Dinge, die man vor allem anderen wissen sollte.

Sie müssen nicht verstehen, wie das Internet funktioniert, um dort sicher zu sein. Sie brauchen vier Gewohnheiten. Diese Seite erklärt jede einzelne, warum sie wichtig ist und was genau zu tun ist. Nichts davon dauert länger als einen Nachmittag.

Länge schlägt Cleverness

In die meisten Konten wird nicht eingebrochen. Sie werden mit einem Passwort geöffnet, das woanders durchgesickert ist. Wenn ein Geschäft, ein Spiel oder ein altes Forum gehackt wird, landen die E-Mail- und Passwortpaare auf Listen, und jemand probiert sie überall aus. Wenn Sie an zwei Orten dasselbe Passwort verwenden, ist ein Einbruch beim schwächeren ein Einbruch bei beiden.

Buchstaben durch Symbole zu ersetzen, hilft nicht so sehr, wie viele denken. Ein Passwort wie Pa$$w0rd! ist kurz und vorhersehbar. Vier unzusammenhängende Wörter hintereinander sind viel schwerer zu knacken und viel leichter zu merken.

Tun Sie dies

  • Verwenden Sie ein anderes Passwort für Ihre E-Mail, Ihre Bank und Ihre wichtigsten Social-Media-Konten. Wenn Sie nur drei reparieren, reparieren Sie diese drei.
  • Machen Sie sie lang. Vier unzusammenhängende Wörter schlagen acht durcheinandergewürfelte Zeichen.
  • Aktivieren Sie die Zwei-Faktor-Anmeldung, wo immer sie angeboten wird. Eine App, die Codes generiert, ist sicherer als Codes per Textnachricht, da eine Telefonnummer gestohlen werden kann.
  • Lassen Sie Ihr Telefon oder Ihren Browser Passwörter für Sie speichern, oder verwenden Sie einen Passwort-Manager. Eine geschriebene Liste in einer Schublade zu Hause ist ebenfalls in Ordnung. Die Gefahr liegt in der Wiederverwendung, nicht in der Speicherung.

Ihr E-Mail-Konto ist der Hauptschlüssel

Fast jedes andere Konto kann über Ihre E-Mail zurückgesetzt werden. Wenn jemand dort eindringt, benötigt er keines Ihrer anderen Passwörter - er kann einfach jede Seite um einen Link zum Zurücksetzen bitten. Schützen Sie dieses eine Konto stärker als den Rest und überprüfen Sie, ob die Wiederherstellungstelefonnummer und die Backup-Adresse dort noch Ihnen gehören.

Wissenswert

Sie können unter haveibeenpwned.com, einem kostenlosen Dienst des Sicherheitsforschers Troy Hunt, überprüfen, ob eine Ihrer Adressen in einem bekannten Datenleck aufgetaucht ist. Wenn ja, ändern Sie das Passwort überall, wo Sie es verwendet haben. Auf der Liste zu stehen ist häufig und kein Zeichen dafür, dass Sie etwas falsch gemacht haben.

Ein Beitrag enthält mehr als das Bild

Wenn Sie etwas online stellen, teilen Sie drei Dinge auf einmal: was im Rahmen ist, was drumherum ist und wer es weitergeben darf. Das erste ist offensichtlich. Die anderen beiden sind das, was die Leute unvorsichtig werden lässt.

Was der Hintergrund verrät

Ein Foto, das auf Ihrer Türschwelle aufgenommen wurde, kann eine Hausnummer zeigen. Ein Foto im Schulpullover zeigt, welche Schule. Ein Bus in der Ecke zeigt eine Route, und eine Route zeigt ein Viertel. Nichts davon ist für sich genommen wichtig. Zusammen ermöglichen sie es einer fremden Person herauszufinden, wo ein Kind an einem Dienstag um halb vier ist.

Über versteckte Fotodaten

Fotos von einem Telefon können den genauen Ort, an dem sie aufgenommen wurden, in der Datei selbst speichern. Die großen sozialen Plattformen entfernen dies beim Hochladen, aber eine direkt gesendete Datei - als E-Mail-Anhang oder als Dokument statt als Foto in einer Chat-App - behält es oft. Wenn Sie eine Originaldatei an jemanden senden, den Sie nicht gut kennen, senden Sie sie als Foto, nicht als Datei.

Dinge, die es nie wert sind, gepostet zu werden

  • Ihre Privatadresse, der Name Ihrer Schule oder Ihres Arbeitsplatzes oder ein Foto, das eines davon deutlich zeigt.
  • Ihr vollständiges Geburtsdatum zusammen mit Ihrem vollständigen Namen. Zusammen werden sie verwendet, um die Identität zu beweisen.
  • Bordkarten, Tickets, Bankkarten oder offizielle Briefe, selbst wenn sie teilweise verdeckt sind. Die Codes darauf enthalten mehr, als es aussieht.
  • Ein Live-Standort. Zu posten, wo Sie jetzt sind, ist etwas anderes, als zu posten, wo Sie letzte Woche waren.

Dringlichkeit ist der Hebel

Betrügereien unterscheiden sich an der Oberfläche stark. Ein Paket, das nicht zugestellt werden kann, eine Bankwarnung, eine Steuerrückzahlung, ein Freund, der sein Telefon verloren hat und Geld braucht, ein Job, der zu gut bezahlt. Darunter machen fast alle dasselbe.

  • Sie schaffen eine Frist. Handeln Sie jetzt, heute, oder das Konto wird geschlossen und das Geld ist weg.
  • Sie leihen sich Autorität. Eine Bank, die Polizei, ein Lieferdienst, eine Plattform, die Sie tatsächlich nutzen.
  • Sie bitten Sie, es geheim zu halten, oder am Telefon zu bleiben, während Sie handeln, damit niemand Sie davon abhält.
  • Sie wollen eine ungewöhnliche Zahlung: Geschenkkarten-Codes, eine Überweisung auf ein neues Konto, Kryptowährung. All dies ist schwer oder unmöglich rückgängig zu machen, was genau der Grund ist, warum danach gefragt wird.

Wenn eine Nachricht drei dieser vier Punkte erfüllt, handelt es sich um einen Betrug, egal was darin steht.

Der Schritt, der fast alles vereitelt

Halten Sie inne und stellen Sie den Kontakt selbst über einen Weg her, dem Sie bereits vertrauen. Legen Sie auf und wählen Sie die Nummer, die auf Ihrer Bankkarte steht. Öffnen Sie die App des Lieferdienstes, anstatt auf den Link zu tippen. Rufen Sie Ihren Enkel unter der Nummer an, die Sie schon immer für ihn hatten. Eine echte Organisation hat nichts dagegen, wenn Sie sie zurückrufen. Eine betrügerische Person kann das nicht überstehen.

Zwei Dinge, nach denen niemand Legitimes jemals fragen wird

Keine Bank, Plattform, Steuerbehörde oder Polizei wird nach Ihrem vollständigen Passwort oder nach einem Einmalcode fragen, der an Ihr Telefon gesendet wurde. Diese Codes existieren, um andere aus Ihrem Konto herauszuhalten. Wenn Sie einen laut vorlesen, übergeben Sie das Konto. Wenn jemand danach fragt, sagt Ihnen das allein schon, wer er ist.

Einen Link prüfen, bevor Sie darauf tippen

Der Teil einer Webadresse, der wichtig ist, sind die letzten beiden Wörter vor dem ersten einfachen Schrägstrich. In bank.example-secure.com/login ist die echte Website example-secure.com, nicht Ihre Bank. Auf einem Computer können Sie den Zeiger über einem Link ruhen lassen und die echte Adresse unten im Fenster lesen. Auf einem Telefon drücken und halten Sie, anstatt zu tippen, und die Adresse erscheint.

Fünf Fragen, die bei jeder App funktionieren

Einstellungsmenüs werden ständig neu gestaltet, sodass eine Schritt-für-Schritt-Anleitung für eine App in Monaten veraltet ist. Die Fragen ändern sich nicht. Öffnen Sie den Datenschutzbereich einer beliebigen App und finden Sie die Antwort auf jede dieser Fragen.

  1. Wer kann sehen, was ich poste? Stellen Sie es auf Freunde oder Follower ein, die Sie genehmigt haben, nicht auf alle.
  2. Wer kann mir Nachrichten senden? Beschränken Sie dies auf Personen, denen Sie bereits folgen oder die Sie akzeptiert haben. Diese eine Einstellung entfernt die meisten unerwünschten Kontakte.
  3. Wer kann mich finden? Schalten Sie die Optionen aus, mit denen Personen Ihr Profil anhand der Telefonnummer oder E-Mail-Adresse finden können.
  4. Wird mein Standort geteilt? Überprüfen Sie sowohl die Standortfreigabe der App selbst als auch die Berechtigung Ihres Telefons für diese App. Stellen Sie sie auf "während der Nutzung der App" oder aus.
  5. Wer steht auf meiner Liste? Scrollen Sie durch Ihre Follower oder Freunde. Entfernen Sie alle, die Sie nicht zuordnen können. Sie schulden niemandem eine Verbindung.

Machen Sie es zusammen

Wenn Sie einem Kind oder einem älteren Verwandten helfen, setzen Sie sich neben sie und lassen Sie sie die Tasten drücken, während Sie die Fragen vorlesen. Menschen erinnern sich an das, was sie selbst getan haben, und ein Kind, das an der Festlegung der Regeln beteiligt war, kommt viel eher zu Ihnen, wenn etwas schiefgeht.
